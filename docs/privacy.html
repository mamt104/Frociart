Frociart

Il progetto resta tuo.

Frociart funziona sul dispositivo e non richiede un account. I progetti e le preferenze vengono salvati localmente, senza sincronizzazione o invio automatico a servizi esterni.

Quando apri un file dal sito

Il browser legge il file sul dispositivo e ne controlla struttura e dimensione. Il contenuto non viene caricato su GitHub o su altri server. Il comando di apertura passa il diagramma all'app come documento da salvare: non ne avvia l'esecuzione.

Sito e download

Il sito non usa strumenti di analisi del traffico né risorse pubblicitarie. GitHub ospita le pagine e i pacchetti e può registrare indirizzi IP e informazioni tecniche di accesso secondo la propria informativa.

Leggi l'informativa privacy di GitHub

Dati locali e diagnostica

La diagnostica e la cronologia dei file recenti restano sul PC e non vengono inviate automaticamente. Per ritrovare progetti precedenti, Windows può leggere i file .frociart e .flow nelle cartelle Documenti e Documenti/Frociart e i relativi collegamenti nell’elenco Recenti di Windows. Android mostra i progetti già conservati nell’archivio locale dell’app. Le pagine esterne seguono le rispettive informative.

File e integrità

L'importazione accetta progetti fino a 4 MB, con un massimo di 500 blocchi e 1.500 collegamenti. Conserva una copia dei documenti importanti. Gli hash SHA256 dei pacchetti sono disponibili nella sezione download.

Torna a Frociart

I metadati troppo annidati o complessi non vengono aperti nell’anteprima del browser. Il sito non modifica il file originale né crea una copia ridotta. I collegamenti all’app rispettano limiti più stretti dell’anteprima: se i metadati non sono compatibili, il collegamento viene disattivato. Il download conserva il file integrale; verificane la compatibilità prima di aprirlo nell’app.
